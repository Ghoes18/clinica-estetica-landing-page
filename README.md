# Clínica de Estética - Landing Page

Uma landing page moderna e elegante para clínica de estética, desenvolvida com React, Vite e Tailwind CSS.

## 🚀 Tecnologias Utilizadas

- **React 19** - Framework JavaScript
- **Vite** - Build tool e dev server
- **Tailwind CSS v4** - Framework CSS
- **Framer Motion** - Animações
- **Lucide React** - Ícones

## 🎨 Características

- Design responsivo e moderno
- Estética feminina com tons pastel
- Animações suaves e elegantes
- Seções: Hero, Serviços, Sobre, Resultados, Depoimentos, Contato
- Formulário de contato funcional
- Otimizado para SEO

## 📦 Instalação

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/clinica-estetica-landing-page.git

# Entre no diretório
cd clinica-estetica-landing-page

# Instale as dependências
npm install

# Execute o projeto em desenvolvimento
npm run dev
```

## 🚀 Deploy no GitHub Pages

```bash
# Faça o build do projeto
npm run build

# Deploy para GitHub Pages
npm run deploy
```
